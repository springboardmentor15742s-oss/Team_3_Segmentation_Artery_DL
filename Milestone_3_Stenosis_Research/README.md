# Milestone 3 – Stenosis Detection Research

## Objective

To understand the workflow for detecting and analyzing stenosis in coronary angiography images.

## Research and Understanding

Studied the following components of the stenosis detection pipeline:

1. Development of a stenosis detection pipeline.
2. Extraction of stenosis candidate regions.
3. Training a stenosis classification or detection model.
4. Implementation of stenosis localization.
5. Implementation of stenosis severity classification.

## Areas Explored

* Coronary artery segmentation.
* Stenosis candidate identification.
* Vessel centerline analysis.
* Vessel diameter measurement.
* Stenosis localization and severity estimation.

## Current Status

Research and understanding of the proposed stenosis detection workflow.

## Future Work

* Implement stenosis candidate-region extraction.
* Develop and evaluate a stenosis detection model.
* Implement stenosis localization.
* Explore stenosis severity classification.

**Note:** This folder documents research and planned implementation. It does not claim that the complete stenosis detection pipeline has been implemented.
