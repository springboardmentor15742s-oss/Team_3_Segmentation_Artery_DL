# Milestone 2 – Deep Learning-Based Artery Segmentation

## Objective

To implement and compare deep learning models for coronary artery segmentation using the ARCADE dataset.

## Models Implemented

1. U-Net
2. Attention U-Net

## Work Completed

* Prepared image and mask samples.
* Implemented the U-Net architecture using PyTorch.
* Implemented the Attention U-Net architecture.
* Trained both models.
* Evaluated segmentation performance.
* Compared model performance using Dice Score, IoU, Precision, Recall, and Accuracy.
* Generated model comparison graphs and performance reports.

## Tools and Libraries

* Python
* PyTorch
* NumPy
* Pandas
* Matplotlib
* Google Colab

## Outputs

* Model comparison results.
* Training history.
* Per-image Dice scores.
* Segmentation prediction visualizations.
* Performance report.

## Note

These are preliminary experimental results using a limited dataset sample. They are not clinically validated.
