# Dataset Exploration and Preparation

## Dataset

ARCADE – Automatic Region-based Coronary Artery Disease Diagnostics.

## Work Performed

* Downloaded and explored the ARCADE dataset.
* Examined the dataset directory structure.
* Inspected syntax and stenosis annotation JSON files.
* Analyzed image dimensions and annotation information.
* Explored polygon annotations for segmentation-mask preparation.
* Selected 50 images for preliminary segmentation experiments.
* Prepared 40 training images and 10 validation images.

## Tools Used

* Python
* OpenCV
* NumPy
* JSON
* PyTorch

## Outcome

Explored the dataset and prepared a small sample of image-mask pairs for preliminary artery segmentation experiments.

## Note

The complete ARCADE dataset is not included in this repository because of its large file size.
