# Milestone 1 – Image Preprocessing

## Objective

To explore basic image preprocessing techniques for improving coronary angiography image quality before further analysis.

## Techniques Explored

* Image loading and validation using OpenCV.
* Image normalization.
* Gaussian Blur for noise reduction.
* CLAHE (Contrast Limited Adaptive Histogram Equalization) for contrast enhancement.
* Visualization of original and processed images.

## Tools and Libraries

* Python
* OpenCV
* NumPy
* Matplotlib

## Outcome

Developed a preliminary image preprocessing prototype and explored techniques that can be used as an initial stage in the artery analysis workflow.

**Note:** This was a preliminary prototype, not a fully validated preprocessing pipeline on the complete ARCADE dataset.
